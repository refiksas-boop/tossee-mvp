📋 Common Issues & Solutions

❌ "Unexpected end of JSON input"
→ Your n8n webhook is returning empty or invalid response
→ Check n8n workflow is ACTIVE and SAVED
→ Make sure "Respond to Webhook" node is connected

❌ CORS Error
→ Add "Set" node in n8n before "Respond to Webhook"
→ Set header: Access-Control-Allow-Origin = *

❌ 404 Not Found
→ Check webhook URL is correct
→ Verify workflow is active in n8n

✅ Expected Response Format
→ Matching: { "ok": true, "status": "waiting" }
→ Signaling: { "ok": true, "message": "..." }
